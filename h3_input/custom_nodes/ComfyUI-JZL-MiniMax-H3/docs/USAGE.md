# MiniMax-H3 生成管理器 · 使用说明

> 一个节点完成 **剧本分段 → 参考调度 → 编码 → 采样 → 解码** 全流程，输出生成总线，
> 无缝对接「视频保存分配」与 VHS（VideoHelperSuite）保存，亦支持 ffmpeg 逐段落盘 / 自动合并。

---

## 一、快速上手（最小工作流）

1. 添加节点：**JZL/MiniMax** → `JZL - 🤖 MiniMax-H3短剧导演台Pro`
2. 接好模型输入：**主模型 / CLIP / 视觉VAE / 音频VAE**（含视频或音频参考时必须接「音频VAE」）
3. 在节点表面 **📝 提示词** 框输入故事 / 剧本（可用 `@` 引用素材）
4. 点击按钮「📁 参考素材管理」上传并配置素材（图片 / 视频 / 音频）
5. 设置「生成视频数量」（默认「**剧情决定**」= LLM 按剧情时间线长度 ÷ 每段时长自动定段数；也可手动指定 1/2/3/4/6/9/12/16/20/26/32/40/48/56 段）、画幅、每段时长等参数
6. 运行，输出 **图像 / 音频（列表）** + **已处理剧本**

> 提示：不接模型输入也能运行——此时只做「剧本分段 + 调度」，不做采样解码（日志会提示缺少模型）。

## 二、运行模式（按你的处境选）

| 模式 | 什么时候选它 |
|---|---|
| **🛠️ 故事拆解模式** | **你有一个已经满意的故事，想直接生成视频** → 选这个。（按情节把故事拆成 N 段；不改剧情、不新增对白） |
| **📚 故事扩展模式** | 故事太短或太简，想**先扩写成丰满正文再拆解** → 选这个。（纯文本处理，不生成视频） |
| **📝 仅提示词输出** | **你有故事，只想先看看拆解出来的提示词、暂不生成视频** → 选这个。（拆解 + 增强后把完整分段剧本从「已处理剧本」端口输出；无需接模型） |
| **🪄 穿透生成模式** | **你已经用「仅提示词输出」拿到满意的提示词**，把它粘进提示词框、直接生成视频 → 选这个。（跳过 LLM 拆解与增强；**必须使用「拆解模式」拆解好的提示词**，格式不对会直接报错终止、不生成） |

> 推荐流程：`📝 仅提示词输出` 调提示词 → 满意后切 `🪄 穿透生成模式` 用同一份提示词出片。
>
> **段数说明**：默认「**剧情决定**」——LLM 先按**剧情时间线长度**（不是字数）判断需要多少总时长，再按你设定的每段时长自动决定段数，避免「选的段数与剧情不匹配」。
>
> **段落字段名（中文 / 英文都支持）**：中文提示词用 `**时长**`、`**场景**`、`**角色**`、`**道具**` 等；英文提示词用 `**Duration**`、`**Scene**`、`**Characters**`、`**Props**` 等，节点两种都能正确识别。
> **每段视频时长取自该段 `时长`/`Duration` 字段**（与节点「每段视频时长」设置无关，这就是逐段动态时长）；只有该字段缺失时，才回退用节点的「每段视频时长」。
>
> **输入要求**：`🛠️ 故事拆解模式` / `📚 故事扩写模式` 吃的是**自然语言故事**；若输入里含已拆解的标签（`===H3_PROMPT===`、`[SHOT_START]`、`subject_definitions:`、`### Video_001` 等）会直接报错终止，请改用 `🪄 穿透生成模式`。
>
> **识图（可选）**：`大语言模型配置 → 开关` 里的「**开启拆解识图**」「**开启扩写识图**」会把「参考素材管理」中**已启用**、且**素材名与故事正文同名**的图片（角色/场景/道具）连同故事一起交给 LLM，让分段描述/扩写内容贴合参考图外观（发型与发饰、服装款式置色、道具造型、场景环境与光线）；没有同名图片会自动跳过（不影响原有纯文本流程）。
> - **本地模型**：需先在「本地 LLM 模型」里选择 **视觉模块 mmproj** 与 **Chat Handler**（未配置会打印警告并自动跳过识图）；
> - **在线 API**：需选择**视觉模型**（默认已为 `deepseek-v4-flash-vision-exp`；Anthropic / Gemini 暂不支持，会自动降级为纯文本）；
> - 单图会缩放到最长边 1024 再发送，单次最多 6 张（超出按 角色→场景→道具 顺序截断）。

## 三、素材与参考调度

- **素材引用上限**：图片 ≤9 / 视频 ≤3 / 音频 ≤3，总参考数 ≤12（官方上限）
- 在提示词中用 `@素材名` 引用；或由场景 / 视频 / 音频调度指令（`类型:槽位名`）自动匹配
- 生成路径按引用内容自动推断：有视频 → 多参考（REF2VA）；否则按参考图数量选择首尾帧 / 首帧 / 纯文本
- 前端「🎯 参考元素切换」可在 **纯文本 / @引用着色** 之间切换

## 四、界面按钮（4×2）

| 📁 参考素材管理 | 📝 剧本拆解配置 | 🎭 采样解码设置 | 🎯 镜头参数预设 |
|---|---|---|---|
| ➕ 常用提示词元素 | 🎯 参考元素切换 | 💾 视频保存设置 | 📖 节点使用说明 |

### 💾 视频保存设置
- **保存模式**（原节点表面选项已移入本面板）：`分段保存`（逐段输出，接 VHS）/ `拼接保存`（合并为一段再输出）——仅影响下游 VHS，保留原有逻辑
- **分段视频自动保存**：勾选后**每段跑完立即用 ffmpeg 落盘 mp4** 到指定目录（`segment_01.mp4`…），不依赖下游 VHS，中途崩溃已生成段落不丢失
- **分段视频自动合并**：勾选后把落盘的各段 mp4 **按顺序拼接为完整一个视频**（无论保存模式；未开自动保存时内部临时落盘，合并后自动清理）

## 五、采样与解码

- 采样：`res_multistep` / `euler` 等 K 采样器，调度器 `simple` / `karras` 等，步数 / CFG 可调
- 解码：视频 `XB-BOX - VAE解码（原版优化）`；音频 `VAE解码（音频）`
- **解码前清理**：`卸载显存模型`（生成结束统一卸载释放）/ `不做清理`
- 节点为**逐段顺序生成**：每段「采样→解码→写入总线→（可选落盘）」完成后才进入下一段，日志 `── 分段 N/M 生成开始…` 依次推进

## 六、输出说明

| 端口 | 类型 | 说明 |
|---|---|---|
| 图像 | IMAGE 列表 | 每段视频帧（分段保存）或拼接后一段（拼接保存） |
| 音频 | AUDIO 列表 | 每段音频（与图像一一对应） |
| 已处理剧本 | STRING | 全部 LLM 处理后的剧本 / 提示词文本 |

> 配合「JZL - 💾 视频保存分配」节点：把「生成总线」输出接上，按组拆分后每组接一个 VHS Video Combine 即可逐段保存成 mp4。

## 七、常见问题

- **没有生成视频，只有分段？** 检查是否接好 CLIP / VAE / model；含视频或音频参考还需接 audio_vae。
- **视频数量改了没生效？** 确认「剧本拆解配置」中固定种子时参数已保存；随机种子每次运行都会重跑。
- **50 系显卡（sm120）装了 xformers，每段都报 `No operator found for memory_efficient_attention_forward` / `capability <= (9, 0)`？** 这是 xformers 的 cutlass attention 没有为 sm120 编译（只支持 ≤ sm90），与节点本身无关。导演台**已自动**在采样前回退到 PyTorch SDPA（无需卸载 xformers）。若仍报错：① 工作流里若用了「Model Attention Backend」节点，把 backend 改为 `pytorch attention`；② 启动 ComfyUI 加参数 `--use-pytorch-cross-attention`；③ 卸载 xformers（`pip uninstall xformers`）。
- **想跑一段存一段？** 在「💾 视频保存设置」勾选「分段视频自动保存」并填路径，每段生成完立即落盘。
- **ffmpeg 不可用？** 节点优先使用 ComfyUI 自带的 imageio-ffmpeg，若仍报错请确认环境已安装 ffmpeg。
